# India Census 2011 Map Visualization

Interactive Streamlit app to visualize India’s census 2011 data at the district level.

- **Color** represents the secondary parameter (e.g., population, literacy rate)  
- **Size** represents the primary parameter (e.g., area, population)  
- Filter by state using the sidebar  



Try the interactive app here: [Open App](https://rohan17062-india-census-2011-app-b0sacd.streamlit.app/)
